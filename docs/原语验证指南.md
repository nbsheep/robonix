# drone_bridge 原语验证指南

> 适用版本：drone_bridge v1.0.0（对齐 Web HTTP API v4.0），RC Pro IP: `10.225.57.15`

---

## 前置条件

- [x] RC Pro 开机，连上 WiFi（与 PC 同一网络）
- [x] Drone_test APK 已打开（AutomatedFlightActivity 页面）
- [x] 无人机已开机并与 RC Pro 对频
- [x] PC 与 RC Pro 在同一网络下

---

## 第 1 步：验证网络连通性（Windows / WSL2 均可）

打开终端，执行：

```bash
curl http://10.225.57.15:8080/api/status
```

**期望输出：** JSON 格式的飞行状态，包含 `"sdkRegistered":true` 和 `"productConnected":true`，`"missionState"` 为合法枚举（如 `IDLE`）。

如果失败：
- 检查 RC Pro WiFi 是否连接
- 检查 Drone_test APK 是否打开
- 检查 IP 是否正确（RC Pro 设置 → WLAN → 查看 IP）

---

## 第 2 步：Standalone 模式测试（Windows，不需要 Robonix）

```powershell
cd C:\Users\nice\Desktop\drone_bridge
python drone_bridge\main.py
```

> 注意：Windows 上用 `python` 不是 `python3`

进入交互 REPL 后，安全地测试查询类命令：

```
drone> status        # 查看原始 /api/status
drone> state         # 查看完整状态（status + GPS）
drone> video         # 获取视频流 URL
drone> q             # 退出
```

**期望输出（`state`）：**
```json
{"missionState":"IDLE","altitude":0.0,"sdkRegistered":true,"productConnected":true,
 "operationMode":"STANDBY","vsEnabled":true,"latitude":30.12,"longitude":120.65}
```

⚠️ **不要在这里测 `takeoff` / `vel` / `rth`**，除非飞机在室外安全环境下！

## 第 3 步：rbnx boot 集成测试（WSL2）

### 3.1 启动 WSL2

```powershell
wsl
```

### 3.2 确认文件是最新的

```bash
grep "10.225.57.15" ~/my-robot/primitives/drone_bridge/drone_bridge/main.py
```

应该输出：`RC_PRO_IP = os.environ.get("RC_PRO_IP", "10.225.57.15")`

如果还是旧 IP，重新同步：

```bash
rm -rf ~/my-robot/primitives/drone_bridge
cp -r /mnt/c/Users/nice/Desktop/drone_bridge ~/my-robot/primitives/drone_bridge
```

### 3.3 确认 manifest 配置正确

```bash
cat ~/my-robot/robonix_manifest.yaml
```

应包含：
```yaml
primitive:
  - name: drone_bridge
    path: ./primitives/drone_bridge
    config:
      rc_pro_ip: "10.225.57.15"
      rc_pro_port: 8080
```

### 3.4 启动 rbnx boot

```bash
export PATH="$HOME/.cargo/bin:$PATH"
cd ~/my-robot
rbnx boot
```

**期望输出：**
```
✓ 4 component(s) up; logs under /home/nice/my-robot/rbnx-boot/logs
```

### 3.5 检查 drone_bridge 日志

```bash
cat ~/my-robot/rbnx-boot/logs/drone_bridge.log
```

**关键行：**
```
[drone_bridge] RC Pro: 10.225.57.15:8080
[drone_bridge] ✅ 已连接到 RC Pro (http://10.225.57.15:8080)
registered primitive 'drone_bridge'
state REGISTERED -> INACTIVE
state INACTIVE -> ACTIVE
```

### 3.6 查看已注册的能力

```bash
rbnx caps | grep drone
```

**期望输出：**
```
● drone_bridge [ACTIVE] robonix/primitive/drone (11 caps)
```

### 3.7 查看能力详情

```bash
rbnx describe --provider drone_bridge
```

**期望输出（11 个能力，MCP 类型）：**
```
● drone_bridge [ACTIVE]
    └─ robonix/primitive/drone/takeoff (mcp)
    └─ robonix/primitive/drone/land (mcp)
    └─ robonix/primitive/drone/move_velocity (mcp)
    └─ robonix/primitive/drone/rotate_velocity (mcp)
    └─ robonix/primitive/drone/hover (mcp)
    └─ robonix/primitive/drone/rth (mcp)
    └─ robonix/primitive/drone/gimbal_velocity (mcp)
    └─ robonix/primitive/drone/gimbal_reset (mcp)
    └─ robonix/primitive/drone/camera_capture (mcp)
    └─ robonix/primitive/drone/camera_video (mcp)
    └─ robonix/primitive/drone/state (mcp)
```

> ⚠️ 类型必须是 **mcp** 而非 grpc（executor 硬编码走 `Transport::Mcp`，`rbnx call` 只认 MCP）。

## 第 4 步：rbnx call 冒烟测试

无副作用调用（可随时做）：

```bash
rbnx call robonix/primitive/drone/state
rbnx call robonix/primitive/drone/camera_video
rbnx call robonix/primitive/drone/land          # 固定返回失败（API 无端点），用于验证链路
```

**期望输出：** 终端打印 `[✓ state]` 之类，data 内是 JSON（state 含 missionState/altitude 等；land 返回 success:false 并带中文说明）。

---

## 快速排查

| 症状 | 检查项 |
|------|--------|
| `curl` 不通 | RC Pro WiFi 是否连接？IP 是否变了？APK 是否打开？|
| `curl` 通但 SDK 未激活 | APK 页面是否显示 "✓ SDK已激活"？ |
| `rbnx` 命令找不到 | `export PATH="$HOME/.cargo/bin:$PATH"` |
| `rbnx boot` 报端口占用 | `pkill -f robonix` 清理旧进程 |
| drone_bridge 日志显示 RC Pro 不可达 | 检查 WSL2 网络 — 从 Windows 侧 `curl` 先确认能通 |
| `rbnx caps` 没有 drone_bridge | 检查 manifest 是否配置了 drone_bridge primitive |
| 能力类型显示 grpc 而非 mcp | codegen 是否用了 `--mcp`，driver 是否用 `@drone.mcp` |

---

## 11 个原语能力一览

| 能力 ID | 类型 | 说明 | 底层 HTTP | 安全调用（飞机不开） |
|---------|------|------|-----------|---------------------|
| `drone/takeoff` | MCP | 起飞爬升至指定高度 | `/api/start` | ❌ 需飞机开机 |
| `drone/land` | MCP | 原地降落（⚠️ 无端点，返回失败） | — | ✅ 可调用（验证链路） |
| `drone/move_velocity` | MCP | 机体系 6DOF 速度向量 | `/api/manual` | ❌ 需悬停态 |
| `drone/rotate_velocity` | MCP | 旋转（方向·角速度·时长） | `/api/manual` | ❌ 需悬停态 |
| `drone/hover` | MCP | 紧急悬停 | `/api/stop` | ❌ 需飞机开机 |
| `drone/rth` | MCP | 智能返航 | `/api/gohome` | ❌ 需飞机开机 |
| `drone/gimbal_velocity` | MCP | 云台角速度（俯仰/偏航） | `/api/gimbal` | ❌ 需巡航中 |
| `drone/gimbal_reset` | MCP | 云台回中（平视） | `/api/gimbal level` | ❌ 需巡航中 |
| `drone/camera_capture` | MCP | 触发单张拍照 | `/api/camera photo` | ❌ 需巡航中 |
| `drone/camera_video` | MCP | 获取视频流 URL | `/api/video` | ✅ 可随时调用 |
| `drone/state` | MCP | 完整状态查询 | `/api/status` + `/api/capture_gps` | ✅ 可随时调用 |
